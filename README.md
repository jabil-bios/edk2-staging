# ACPICA-VS2026
Update [**ACPICA**](https://github.com/acpica/acpica) to build with **Visual Studio 2026**.

Generates 32bit and 64bit for Windows.

## HOWTO
1. goto folder **ACPICA\GENERATE\MSVC2026**
2. start **LAUNCH.BAT**
    * **NOTE:** DO NOT START **AcpiComponents.slnx** directly
